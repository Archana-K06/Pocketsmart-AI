# Software Requirements

- Python 3.10 or newer; pip and `venv`.
- Dependencies in `5. Project Development Phase/requirements.txt` (FastAPI, SQLAlchemy, psycopg, google-genai, …).
- Database: SQLite (built in) or PostgreSQL 13+ for production.
- Optional `GEMINI_API_KEY` for AI recommendations (offline mode works without it).
- `SECRET_KEY` for JWT signing (required in production).
- Modern web browser.

See the repository-root `README.md` for setup and deployment.
