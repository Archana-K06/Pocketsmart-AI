# Features

- **Home Planner** — budget, room types, quantities (lights, fans, furniture, dining tables), style, platforms; calculation table and remaining budget.
- **Party Planner** — budget, guests, event type, venue, needs; category-specific vendor/shopping links (Swiggy, Zomato, BookMyShow, OYO, …).
- **Jewelry Planner** — budget, occasion, style, optional outfit image with Gemini outfit analysis; jeweller and marketplace links.
- **Accounts** — registration, login, logout with server-side revocation, session info/data, idle-session cleanup.
- **History** — per-user storage in SQLite/PostgreSQL, detail view, clear action.
- **Resilience** — validated AI output, configurable Gemini models, offline fallback that always adds up to the budget.
